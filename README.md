# Skills

Skills in this repository can be installed with `npx skills`:

```bash
npx skills add jungm/skills
```

Or:
```bash
npx skills add git@github.com:jungm/skills.git
```

## Available skills

| Skill | Description |
|-------|-------------|
| [jakarta-ee-spec-reader](skills/jakarta-ee-spec-reader/) | Locate, read, and cite Jakarta EE specification documentation |
| [tomee-bugfix](skills/tomee-bugfix/) | Fix a TomEE bug end to end — failing test, fix, Jira issue, pull request, app verification |
| [verify-apache-release](skills/verify-apache-release/) | Verify Apache release integrity — hashes, signatures, KEYS, Maven staging |
